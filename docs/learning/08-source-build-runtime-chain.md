# Source-Build-Runtime Chain

## Established technical concept
Each transition from source to build to runtime requires its own attestation.

## Plain-language explanation
Code on disk, packaged files, and a running process can all be different versions.

## Why AI coding agents struggle
Nearby names and ports look coherent, encouraging agents to collapse boundaries.

## Itzako example
The target source, extension directory, and three listeners are observed, but
their links are not.

## Kratos Agent Guard implementation
Separate manifests, process identities, and qualified provenance links preserve gaps.

## Trade-offs
More instrumentation is required at build and startup time.

## Failure modes
Equating a port, process name, or version with exact artefact bytes.

## Practical exercise
Run the same service from two directories and inspect the difference.

## Transfer
Use the chain for Deal Sniper workers and dashboards.

## Key takeaway
Prove every arrow, not just every node.
