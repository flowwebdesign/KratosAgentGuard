# 29. Existing observability endpoints versus enabling observability

## Established technical concept
Observation can mutate a system when instrumentation must be enabled.
## Plain-language explanation
Using an already authorised read-only endpoint differs from restarting Chrome with debugging.
## Why AI coding agents struggle
Automation tools commonly create their own debug surface.
## Itzako example
Phase 2D does not enable remote debugging, attach broadly, or run Runtime.evaluate.
## Guard implementation
Absent independently proven endpoint provenance, live observation is unavailable.
## Trade-offs
The phase may stop before worker proof, preserving browser authority.
## Failure modes
Launching a debug browser, creating a port, navigating a tab, or evaluating JavaScript.
## Practical exercise
List facts required to prove an endpoint predates an inspection.
## Transfer
Apply the rule to production profiling and temporary admin endpoints.
## Key takeaway
Do not change the observed system merely to make it observable.
